# Инструкция: Настройка голосового выхода и скачивания YouTube

## 1. Настройка голосового выхода (TTS)

### В файле `~/.hermes/config.yaml`:
```yaml
tts:
  provider: edge          # или openai/elevenlabs
  edge:
    voice: ru-RU-DariaNeural  # русский голос
  openai:
    model: gpt-4o-mini-tts
    voice: alloy

voice:
  record_key: ctrl+b
  max_recording_seconds: 120
  auto_tts: false
  beep_enabled: true
  silence_threshold: 200
  silence_duration: 3.0
```

## 2. Скачивание и транскрибация YouTube видео

### Установка:
```bash
# Склонировать репозиторий
git clone https://github.com/samloik/download-video-from-youtube ~/programs/download-video-from-youtube
cd ~/programs/download-video-from-youtube

# Виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# Зависимости
pip install -r requirements.txt
```

### Настройка прокси (если нужен):
```bash
# В config.json:
{
    "default_resolution": 720,
    "default_cookies": "youtube_cookies.txt",
    "output_dir": "./output",
    "default_proxy": "socks5://127.0.0.1:10808"
}
```

## 3. Использование

### Скачивание аудио:
```bash
source venv/bin/activate
python main.py "https://www.youtube.com/watch?v=..." --audio --transcribe
```

### Прямая ссылка:
```bash
python main.py "https://youtu.be/..." --audio --transcribe
```

## 4. Получение выжимки

После транскрипции файл будет в `./output/название_видео.txt`.
Отправьте его в LLM для анализа.

## 5. Проверка статуса

```bash
# Порты прокси
ss -tlnp | grep xray

# Доступные скиллы
hermes skills list
```

## 6. Голосовые функции в Telegram

- Агент может отвечать голосом через `text_to_speech`
- Голосовые сообщения автоматически транскрибируются (STT включен)
- Настройка в разделе `voice:` конфига выше
